# cc500 自举编译器

`cc500.c` 是 [Edmund GRIMLEY EVANS](http://homepage.ntlworld.com/edmund.grimley-evans/cc500/)
的 cc500（Copyright © 2006）的**移植 / 衍生** C 子集编译器。本仓库内按 **GPL-2.0-or-later**
提供，许可证全文见本目录 [`LICENSE`](LICENSE)。

## 在本项目中的角色
mini-os 的自举工具链（v0.27 引入）：guest 内用 cc500 把 C 子集源码编译为 ELF 并运行，
支撑"写-编-跑 / 编译器自编译"闭环（shell `ccrun` / `ccboot`）。

**教学对照定位（2026-09 起）**：与自研 MIT 编译器 minicc（`tools/minicc/`）并列，作为
"一个编译器怎么长大"的活教材——cc500 以 ~2049 行保持极简单遍架构，特性按低成本里程碑
逐个追加（M1~M12，见下），每个里程碑都附带「旧语法产物字节零变化 + 自举 P1==P2 不动点」
的回归证明。

## 当前语言快照（教学里程碑后）

- 类型：`int` / `char`（`char*` 声明中 `*` 仅被语法跳过，无真指针类型语义）
- 字面量：十进制整数、**十六进制 `0x…`（M9）**、字符 `'x'`、字符串（含 `\xNN \n \t` 转义，
  call/pop 内联取址）
- 运算符：`+ - * / %`、`<< >>`、`< <= > >=`、`== !=`、`& | ^`、`~ !` 一元、`=` 赋值、
  **`+= -= *= %= /= <<= >>= &= |= ^=` 复合赋值（M4/M9b）**、**`&&` / `||` 短路（M6）**、
  **`?:` 三目（M7）**、**`++` / `--` 前/后缀（M8）**
- 语句：`{}`、声明（含初始化）、`if/else`、`while`、**`for` / `do-while`（M1）**、`return`、
  **`break` / `continue`（M5）**、**`goto` / 标签（M11）**、**`switch` / `case` / `default`（M12）**
- 函数：多参、递归、前向引用（U/D 链式回填）、间接 `call *%eax`

## 教学里程碑（"编译器长大"路线图）

> M10 编号未使用（M9b 之后直接 M11）；M5 起全部于 2026-09-06~09-07 落地，
> 归档见 changelog v1.5「cc500 教学里程碑」段。

| 里程碑 | 新增语法 | 要点 | 日期 |
| --- | --- | --- | --- |
| M1 | `for` / `do-while` | 无 AST 单遍下 for 的 step 后置 = 双跳摆渡布局（`jmp L_body` 跳过 step 区、body 尾 `jmp L_step`）；step 原地发射无重定位 | — |
| M2 | 一元 `- ! ~`、`^` | unary 层插 postfix/additive 之间，"先试前缀失败回退"消歧同一 token；operator 词法精确化（原 `=!` 被宽集合吞并） | — |
| M3 | `* / %` | multiplicative 层；imul/idiv 路径与 minicc 同编码；自举输入上限 32KB→64KB | — |
| M4 | `+= -= *= %=` 复合赋值 | 算术复用 `binary2`（emit 与对应二元运算同字节）+ `'='` 的 lvalue 地址保持存回；token 从 `+-*%` 侧合成 `X=`；**修复 `a += 1` 被静默编成 `a = 1`**；lvalue 单次求值 | 2026-09-06 |
| M5 | `break` / `continue` | 循环帧栈管理未决跳转（break/continue 挂起水位），循环退出/continue 目标点统一回填 rel32；支持嵌套与同层多次；循环外报错（纪律#2） | 2026-09-06 |
| M6 | `&&` / `\|\|` 短路 | 表达式内跳转实现短路求值（左 false/true 即跳，不评估右操作数） | 2026-09-06 |
| M7 | `?:` 三目 | 条件表达式；两分支值路径 + 收尾统一回填 | 2026-09-06 |
| M8 | `++` / `--` 前/后缀 | 前后置区分 + lvalue 保持；**前缀栈记账错位修复（PR #140，2026-09-08）**——值弹栈改走 `binary2` 配对记账 | 2026-09-06 |
| M9 | `0x…` 十六进制字面量 | 十六进制整数字面量（`0x` 前缀解析） | 2026-09-07 |
| M9b | `/= <<= >>= &= |= ^=` | M4 之外的复合赋值补齐（token 合成 + `binary2` 复用） | 2026-09-07 |
| M11 | `goto` / 标签 | 源标签 `lbl_define` + `goto`（可前向挂起/后向直回填，`emit_goto_anchor` 与 switch `.exit` 复用） | 2026-09-07 |
| M12 | `switch` / `case` / `default` | switch 帧栈（exit 锚/default 起点/case 表）+ 无常量折叠（case 限整型字面量）；**重复 case 常量拒绝（PR #142，外部审计）**；switch 内 `break` 转 goto .exit | 2026-09-07 |

**纪律（每里程碑强制）**：
1. 新特性只加**新增分支**，不改任何既有 emit 路径 → cc500 自身源码不使用新语法，
   自举不动点 P1==P2 逐字节保持；
2. 不支持的语法仍走 `error()`，绝不静默产出坏码；
3. 每特性三同步：`tests/test_cc500.sh` 宿主编译断言 + guest 运行语义断言 + 本表更新。

## 验证
`tests/test_cc500.sh`：宿主 hostcc 层（F-1/F-2/F-3 症状对立 + 各里程碑编译断言 +
`+=` load 旧值编码锁定 + 非 lvalue/`/=` 报错断言 + M5 循环外报错 + M12 重复 case 拒绝）+
guest 层（ccboot 自举 P1==P2 + ccrun 运行语义，含 for/do/一元/^~/乘除模/优先级/复合赋值/
lvalue 单次求值/短路/三目/自增自减/goto/switch 用例）。

## 已知限制
- **数组声明不支持**（C 子集边界，非缺陷）：`int arr[4]` / `char s[8]` 在文法层被拒
  （声明文法只有 `type id [=expr] ;`，无 `[` 分支）；但对**已有缓冲**的下标访问 `p[i]` 受支持
  （集合数据用独立变量 + 手动缓冲 + 下标模拟）。
- 输入**动态扩容，无硬上限**（OBS-CC-5）：初配 64KB，读满则翻倍扩容（`input_grow`），
  不再有"超 64KB 显式拒绝"的硬截断；
- 除零 / `INT_MIN / -1` / 有符号溢出为 UB（x86 idiv 自然行为，与宿主 C 一致）；
- 单线程、无重入（编译期全局状态），递归下降有 `cc_depth` 512 护栏。

## 与内核的集成
- 源码 `cc500.c` 以原始字节 blob 嵌入内核（Makefile `cc500_csrc.o`），boot 时写入
  initramfs `/cc500.c`；
- 编译产物可经 shell `ccrun <src> <out>` 调用，`ccboot` 做二次自举字节一致性校验。
