## 二进制处理（关键）

`harness/` 内含两个预编译 ELF 二进制，**已加入仓库 `.gitignore`，不进入 git 历史**：

| 文件 | 性质 | sha256 |
|---|---|---|
| `hostminicc32` | ELF 32-bit x86 静态可执行（被测编译器本体，无 `.interp`/`.dynamic`，零 libc 依赖） | `2cf9c9396ff6187fea8b46dad26cdca618c4ada5ae2154aefdf7b16846bb35ef` |
| `runmin32` | ELF 32-bit x86 静态可执行（产物执行器，同上） | `db186074ac19830fc223a729a6bbc4b5d579e3c24df16924da33c839f774f454` |

理由：
1. git 对二进制不 delta，入库会污染历史；
2. `hostminicc32` 是**预编译的编译器本身**，属最不该盲信预编译件之物（信任链需可验证）；
3. 本机为 Windows，两二进制是 Linux ELF（需 x86-64 Linux 开启 ia32 执行），**此处无法运行**。

## 验证状态：未独立复现（信任，非自验）

- 若日后需在 Linux 上复现：解包后 `N=400 SEED=100 VARS=6 STMTS=8 bash harness/gen_audit.sh`（模式 A）；
  模式 B 需先取得 `tools/minicc/minicc.c` 并设 `MINICC_SRC`。
